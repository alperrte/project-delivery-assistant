# Technology logos

Local copies of technology logos used by the project create page and the project card (no runtime CDN request).

- Most files come from [devicon](https://github.com/devicons/devicon) (MIT License), `*-original.svg` / `django-plain.svg`.
- `anthropic`, `huggingface`, `langchain`, `openai`, `tauri` come from [Simple Icons](https://github.com/simple-icons/simple-icons) (CC0 1.0).
- The logos are trademarks of their respective owners and are used only to identify the technologies a project uses.
- Technologies without a file here (for example Pinecone) are shown as a letter badge by `tech-catalog.ts`.
