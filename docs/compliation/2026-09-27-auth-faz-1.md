# Auth Faz 1 — User identity ve UserSession persistence

**Durum:** Tamamlandı, 27 Eylül 2026. Task'lar: `ALP-AUTH-01`, `ALP-AUTH-02`, `ALP-AUTH-03`. Faz 2'ye başlanmadı.

## Yapılanlar

- [User](../../backend/src/main/java/com/pda/user/domain/entity/User.java) entity'si email, nickname, account/email verification status, global role ve zaman alanlarını tutar. Email ve nickname kullanıcının seçimiyle yazıldığı biçime duyarlı benzersizdir. Nickname 3–32 Unicode harf/rakam/alt çizgi kabul eder. Local hesap factory'si BCrypt ile hash üretir; OAuth hesabı için şema `password_hash = NULL` destekler. Register/login API'si bu fazda yoktur.
- [UserSession](../../backend/src/main/java/com/pda/user/domain/entity/UserSession.java) refresh tokenı yalnız SHA-256 hash olarak persist eder. Süre, son kullanım, rotation ve revoke durumu modellenmiştir. Aktif session repository sorgusu eklendi. JWT üretimi ve replay politikası sonraki Auth task'larındadır.
- [V2__auth_user_session.sql](../../backend/src/main/resources/db/migration/V2__auth_user_session.sql) `users` ve `user_sessions` tablolarını, benzersizlikleri, durum kısıtlarını, kullanıcı FK'sini ve aktif session indeksini kurar. Numara aralığı kullanıcı kararıyla Alper için `V1–V20`, Hamza için `V21–V40` olarak ayrıldı.
- [BackendApplication](../../backend/src/main/java/com/pda/BackendApplication.java) `com.pda` köküne taşındı; Spring ve Spring Modulith modülleri tarayabiliyor. Test giriş referansları ve `.agents/architecture.md` ile `.agents/folder-structure.md` güncellendi.
- Kullanıcı onayıyla [SecurityBaselineConfiguration](../../backend/src/main/java/com/pda/auth/infrastructure/config/SecurityBaselineConfiguration.java) eklendi. Tüm HTTP istekleri reddedilir, CSRF filtresi etkin kalır ve Spring'in varsayılan geçici kullanıcı/şifre üretimi kaldırılır. Bu geçici kural gerçek Auth API task'larında kontrollü olarak genişletilecektir.

## API, ENV ve güvenlik

- Yeni endpoint veya public yol yok. Şu anda HTTP erişimi deny-all; Swagger üzerinden çağrılacak bir Auth API henüz yok.
- `.env`, `.env.example`, `pom.xml` ve `application.properties` değiştirilmedi; yeni ENV/secret yok.
- Password ve refresh token plaintext veritabanına yazılmaz. Şifreler BCrypt, yüksek entropili refresh tokenlar SHA-256 hash olarak saklanır. Test verisindeki hassas değerler çalışma anında üretildi. Token/password loglama eklenmedi.
- OAuth hesap bağlama, register doğrulaması, JWT, cookie, CSRF token taşıma, CORS ve rate limit bu fazın dışında kaldı; bunlar hazır özellik sayılmamalı. İlk Auth endpoint'i açılmadan önce deny-all kuralı kontrollü olarak güncellenmeli.
