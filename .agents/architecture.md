# Mimari kısa özet

**Durum:** Kabul edilmiş teknik plan ve mevcut iskeletin özeti. Bir özelliğin uygulanmış olduğunu tek başına göstermez.

- Ürün: öğrenciler ve küçük ekipler için self-hosted proje yönetimi.
- Backend: tek Spring Boot uygulaması, Spring Modulith ile modül sınırları. Modüller arası senkron iletişim hedef modülün public contract/facade katmanından geçer; başka modülün repository veya entity'sine doğrudan bağımlılık kurulmaz. Olay bildirimi Spring ApplicationEvent ile planlanmıştır. Ayrıntı: `decisions/0001-modular-monolith.md`.
- Frontend: Next.js App Router, TypeScript ve Tailwind. Özellik bazlı düzen hedeflenir; mevcut arayüz scaffold seviyesindedir.
- Veri: PostgreSQL, Spring Data JPA/Hibernate ve Flyway. Yerelde Docker PostgreSQL; production için Neon varsayılan seçenek, fakat uygulama standart PostgreSQL bağlantısı kullanır. Production şema doğrulaması `ddl-auto=validate`. Ayrıntı: `database.md`, `decisions/0002-postgresql.md`.
- API: Spring MVC REST, `/api/v1`; endpoint sözleşmesi özellik uygulanırken belirlenir. Backend input ve erişim denetiminin sahibidir. Ayrıntı: `api.md`.
- Güvenlik: Spring Security, BCrypt, HttpOnly cookie içinde access/refresh JWT, CSRF koruması, açık CORS izin listesi, proje kapsamlı RBAC. Ayrıntı: `SECURITY.md`, `authentication.md`, `decisions/0003-cookie-auth.md`.
- Çalıştırma: Docker Compose içinde frontend, backend, postgres. Production hosting ve domain topolojisi henüz kararlaştırılmadı. Ayrıntı: `deployment.md`.

**Mevcut kod durumu:** Backend giriş sınıfı `com.pda` kökündedir. Auth/User tarafında V2–V7 migration; local register/login/logout/me, refresh rotation, aktif oturumlar, Google/GitHub OAuth login+bağlama, admin bootstrap+zorunlu ilk şifre değişimi ve admin kullanıcı/sistem API'leri uygulanmıştır. Canonical `GlobalRole`/`ProjectRole`/`ProjectPermission`/`PlatformPermission`/`RolePolicy` `com.pda.user` altındadır (deny-by-default; rol adı değil yetki denetlenir); proje rolleri artık geçici değildir (`MODERATOR` kaldırıldı, 8 rol kaldı). Project Service `com.pda.project` altında Organization, Project, ProjectMembership ve ProjectInvitation'ı içerir; V21–V24 migration; Project/Organization/üyelik/kullanıcı arama/davet (create/resend/cancel/reject/accept, best-effort mail) REST API'leri, son Project Manager koruması, `ProjectAccess.hasPermission`/`permissionsForUserInProject` ve `ProjectOverview` (admin özeti) uygulanmıştır. Squad Service `com.pda.squad` altında ayrı bir Spring Modulith modülüdür (yalnız `project.ProjectAccess` ile konuşur); V25 migration ile squad create/update/archive ve PM-only squad üyeliği (yalnız aktif project member eklenebilir) uygulanmıştır. Project tarafında V26 migration ile Success Criteria (checklist, task değildir) ve `Project.changeStatus` ile PLANNING/ACTIVE/ON_HOLD/COMPLETED arası lifecycle geçişleri uygulanmıştır; ARCHIVED yalnız mevcut archive action'ı ile ulaşılabilir. V27 migration ile public GitHub repository bağlama (read-only, allowlist+parse ile SSRF-safe, son commit listesi) uygulanmıştır; private repo/webhook/PR entegrasyonu yoktur, GitHub hatası yalnız ilgili endpoint'i etkiler. Swagger/OpenAPI yalnız `API_DOCS_ENABLED=true` iken açıktır. Diğer iş modülleri henüz iskelet düzeyindedir; frontend varsayılan Next.js sayfası düzeyindedir.
